DTLmorning - User Guide

Guide for the morning summary of local Git repositories.

PowerShellWindowsGit

Goal

DTLmorning displays, at the beginning of a Windows session, a summary of Git repositories that need attention.

Read the Message

Everything is clean

No repository requires a particular action.

Local changes

Some files need to be recorded in Git or committed.

Synchronization

Some repositories have commits to push or remote changes to fetch.

What to Do Next

  1. Identify the repositories listed in the message.
  2. Open the relevant repository in GitDTL or your usual Git tool.
  3. Handle the indicated actions: save, commit, push or synchronize.

Automatic Startup

DTLmorning can be placed in the Windows startup folder through its VBS launcher or a shortcut. It waits a few seconds before analysis to let the desktop load.

Disable

To disable the reminder, remove the launcher or shortcut from the Windows startup folder.
