DTLmorning — Manuel de référence

Référence descriptive de l’assistant matinal de surveillance Git locale.

Type : PowerShellSortie : boîte WindowsMode : lecture seule

Rôle

DTLmorning fournit un résumé bref de l’état des dépôts Git locaux afin d’indiquér les actions qui méritent l’attention au début d’une session Windows.

Analyse Git

Découverte

Le script recherche récursivement les dossiers contenant `.git` à partir d’un dossier racine.

État local

Il distingue fichiers modifiés, fichiers non suivis, éléments indexés et état de synchronisation avec la branche distante.

Priorités d'action

La logique classe les dépôts selon le besoin le plus immédiat : enregistrer des fichiers, valider un commit, publier des commits locaux ou récupérer des commits distants. Cette classification reste descriptive et ne modifie aucun dépôt.

Affichage

La sortie est une boîte de dialogue Windows. Elle condense le nombre de dépôts concernés, les actions principales et une estimation simple du temps nécessaire.

Limites

  • La précision dépend de la sortie Git locale.
  • Aucune opération réseau n'est imposée au-delà des informations déjà disponibles dans l’état Git.
  • L’outil ne remplace pas une revue détaillée dans GitDTL ou Git.
