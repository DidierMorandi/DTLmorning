DTLmorning — Guide utilisateur

Guide du résumé matinal des dépôts Git locaux.

PowerShellWindowsGit

Objectif

DTLmorning affiché, au début d’une session Windows, un résumé des dépôts Git qui nécessitent une action.

Lire le message

Tout est propre

Aucun dépôt ne nécessite d’action particulière.

Modifications locales

Certains fichiers doivent être enregistrés dans Git ou validés dans un commit.

Synchronisation

Certains dépôts ont des commits à publier ou des changements distants à récupérer.

Que faire ensuite

  1. Repérer les dépôts listés dans le message.
  2. Ouvrir le dépôt concerné dans GitDTL ou dans votre outil Git habituel.
  3. Traiter les actions indiquées : enregistrer, valider, publier ou synchroniser.

Démarrage automatique

DTLmorning peut être placé dans le dossier de démarrage Windows vià son lanceur VBS ou un raccourci. Il attend quelques secondes avant l’analyse afin de laisser le bureau se charger.

Désactivation

Pour désactiver le rappel, retirer le lanceur ou le raccourci du dossier de démarrage Windows.
