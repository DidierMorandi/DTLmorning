DTLmorning - Guide utilisateur

Guide du résumé matinal des dépôts Git locaux.

PowerShell Windows Git

Objectif

DTLmorning affiche, au début d'une session Windows, un résumé des dépôts Git qui nécessitent une action.

Le script repère les modifications locales, les changements prêts à valider, les commits à publier et les commits distants à récupérer.

Prérequis

  • Windows avec PowerShell.
  • Git installé et disponible en ligne de commande.
  • Des dépôts Git locaux placés sous le dossier que DTLmorning doit analyser.

Installer le script

1. Vérifier les fichiers

Le dossier DTLmorning doit contenir au minimum ces deux fichiers :

  • DTLmorning.ps1 : le script PowerShell qui inspecte les dépôts Git.
  • DTLmorning.vbs : le lanceur Windows qui démarre le script sans garder de fenêtre PowerShell ouverte.

2. Configurer le lanceur

Ouvrir DTLmorning.vbs dans un éditeur de texte, puis vérifier que la ligne scriptPath pointe vers l'emplacement réel de DTLmorning.ps1.

scriptPath = "C:\Users\Utilisateur\Documents\Secato\outils\DTLmorning\DTLmorning.ps1"

Si le dossier DTLmorning est déplacé, cette ligne doit être mise à jour.

3. Tester manuellement

Avant de l'installer au démarrage, lancer une première exécution depuis PowerShell :

powershell.exe -NoProfile -ExecutionPolicy Bypass -File "C:\Users\Utilisateur\Documents\Secato\outils\DTLmorning\DTLmorning.ps1"

Une boîte de dialogue doit apparaître avec le résumé des dépôts Git trouvés.

4. Lancer au démarrage Windows

  1. Appuyer sur Win + R.
  2. Taper shell:startup, puis appuyer sur Entrée.
  3. Copier DTLmorning.vbs dans le dossier de démarrage qui vient de s'ouvrir.

À la prochaine ouverture de session Windows, DTLmorning se lancera automatiquement.

Lire le message

Tout est propre

Aucun dépôt ne nécessite d'action particulière.

Modifications locales

Certains fichiers doivent être enregistrés dans Git ou validés dans un commit.

Synchronisation

Certains dépôts ont des commits à publier ou des changements distants à récupérer.

Que faire ensuite

  1. Repérer les dépôts listés dans le message.
  2. Ouvrir le dépôt concerné dans GitDTL ou dans votre outil Git habituel.
  3. Traiter les actions indiquées : enregistrer, valider, publier ou synchroniser.

Démarrage automatique

DTLmorning peut être placé dans le dossier de démarrage Windows via son lanceur VBS ou via un raccourci. Le lanceur utilise wscript.exe et démarre PowerShell avec -WindowStyle Hidden, ce qui évite de laisser une fenêtre ouverte.

Variante possible : créer un raccourci dans le dossier de démarrage avec cette cible :

wscript.exe "C:\Users\Utilisateur\Documents\Secato\outils\DTLmorning\DTLmorning.vbs"

Désactivation

Pour désactiver le rappel, ouvrir à nouveau shell:startup, puis supprimer DTLmorning.vbs ou le raccourci DTL Morning.
